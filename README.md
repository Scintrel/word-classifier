# 单词分类app（Word Classification App）

一个跨平台桌面应用（Windows + Mac），用于导入、管理、校验和导出英语单词表。
本项目的核心功能是**根据语义给单词分类**：程序读取单词的中英文释义，自动把单词
按意思分组（食物、科技、情感、自然……），支持多级子分类，并为每个分类结果给出置信度评分。
以及完成了四六级的语义分类，见**`四六级单词分类成果.zip`**。

所有数据都在本地处理，不会上传互联网。

## 主要功能

- **文件导入**：支持 CSV、Excel（.xlsx/.xls）、TXT、JSON 四种格式，拖拽即导入
- **数据校验与自动补全**：自动检查缺失、重复、乱码等问题，并从内置词典补全音标、释义、词性
- **语义分类**：10 个主分类 + 20 多个子分类、600+ 关键词的语义匹配引擎，一键自动分类所有单词
- **单词管理**：浏览、搜索（按字母/词频等排序）、编辑单词与例句、手动调整分类
- **导出**：按全部/分类/难度导出，支持 JSON、CSV、Excel 格式

## 演示成果：四六级单词分类

仓库里的 **`四六级单词分类成果.zip`** 是用本软件对四六级单词表做语义分类的演示成果，
解压后是同一份数据的三种格式：

| 文件 | 格式 |
|------|------|
| `words-all.csv` | CSV |
| `words-all.csv.xlsx` | Excel |
| `words-all.json` | JSON |

## 已知问题

以下问题均**不影响正常使用**，暂不修复：

1. 某些特殊场景下，浅色/深色主题切换会失灵
2. 内置大词典不够准确：演示成果里的所有单词都是四六级单词，但其中一部分在词典里没有四六级标签
3. CSV 和 Excel 两种导出得到的文件实际都是 CSV 内容（Excel 导出暂未真正生成 xlsx 格式）

## 快速开始

```bash
# 安装依赖（第一次运行）
npm install

# 启动开发模式（边改代码边看效果）
npm run dev

# 打包为 Windows 安装包
npm run package:win

# 打包为 Mac 安装包
npm run package:mac
```
